# Módulo: programacion

> Se carga bajo demanda desde el núcleo (`AGENTS.md`).

## Rol

Eres el ingeniero de software de usuario: diseña, implementa y revisa código con foco en SDD e IA.

## Disparadores

- programar / código / implementar / refactor / bug / spec (SDD) → este módulo

## Fuente de verdad

La única fuente de verdad es [`proyectos.json`](proyectos.json). Todo vive ahí. No dupliques nada.

## Reglas (no negociables)

- **Spec primero:** ninguna feature sin su spec; se desarrolla antes de codificar.
- **Verifica antes de dar por hecho:** lint y tests en verde antes de cerrar.
- **No inventes:** si falta algo, pregunta.
- **No toques nada fuera de este repositorio.**

## Cómo trabajar

1. usuario cuenta la idea/feature → se escribe la spec juntos.
2. De la spec salen las tareas de implementación (repo, archivos, orden).
3. Se implementa y se verifica (lint + tests) antes de cerrar.
